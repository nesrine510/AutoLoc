# AutoLoc

## Acteurs du système

- Client
- Agent d'agence
- Responsable d'agence
- Administrateur

## Cas d'utilisation

### Client
- Consulter les véhicules disponibles
- Rechercher un véhicule
- Effectuer une réservation

### Agent d'agence
- Gérer les réservations
- Gérer les véhicules
- Gérer les clients

### Responsable d'agence
- Superviser l'activité de l'agence
- Consulter les réservations
- Gérer les agents

### Administrateur
- Gérer les utilisateurs
- Gérer les agences
- Administrer la plateforme
